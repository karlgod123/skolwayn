Вопросы

Перед стартом

Здесь можно собрать основные ответы, которые обычно нужны перед выбором курса.

Нужно ли уметь программировать заранее?

Для стартовых направлений можно начинать с базового уровня. Конкретные требования лучше указать на странице каждого курса.

Можно ли задавать вопросы преподавателю?

Да. На странице курса можно будет указать формат обратной связи и способ связи с преподавателем.

Что понадобится для обучения?

Для Python и JavaScript достаточно компьютера. Для Arduino дополнительно понадобится комплект платы и компонентов.

Можно ли изучать несколько направлений?

Да. Начните с основной технологии, а затем добавляйте смежные направления по мере роста.
