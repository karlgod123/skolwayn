# Skolwayn — Frontend MVP

Этот пакет содержит только frontend. Backend пользователя не изменён и в архив не включён.

## Запуск
1. Запусти свой текущий FastAPI backend как обычно.
2. Открой папку через VS Code Live Server.
3. Перейди на `index.html`.

## Flow
- Регистрация отправляется на существующий `POST /add_user`.
- После успешной регистрации происходит переход на `main.html`.
- `Запомнить меня` в этой frontend-версии сохраняет имя пользователя в localStorage/sessionStorage только для отображения на главной.
- Это не заменяет настоящую авторизацию.
- `login.html` — только UI. Endpoint `/login` здесь не добавляется.

## Backend
Файл `main.py` специально не входит в этот пакет и не изменяется.
